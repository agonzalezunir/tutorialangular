El primer proyecto

Vamos a generar el primer proyecto de Angular y para ello necesitamos abrir el terminal y ejecutar la siguiente orden
  >ng new primerproyecto

Al hacerlo, nos hará una serie de preguntas (el tipo de CSS, si va a usar SSR (server-side rendering) o SSG (Static Site Generation) y si vamos a utilizar alguna herramienta de IA para el código.
Dejemos las opciones por defecto:
  ✔ Which stylesheet system would you like to use? CSS
  ✔ Do you want to enable Server-Side Rendering (SSR) and Static Site Generation (SSG/Prerendering)? No
  ✔ Which AI tools do you want to configure with Angular best practices? https://angular.dev/ai/develop-with-ai None
