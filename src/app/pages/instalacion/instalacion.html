Instalación de Angular

La instalación de Angular requiere de varios componentes.
En el caso que nos ocupa, lo hemos instalado en una máquina con Linux Manjaro así que los ejemplos están realizados con este sistema operativo.

Las necesidades de instalación según la documentación oficial son las siguientes:
  • Node.js, versión 20.19.0 o más moderna
  • ClI de Angular, para poder lanzar los comandos Angular.
  • TypeScript
  • IDE de programación. En nuestro caso usaremos JetBraing WebStorm
  • Terminal, para lanzar los comandos de la CLI de Angular


En nuestro caso, comenzamos por abrir una ventana de terminal y ejecutar con el administrador de paquetes de Manjaro la instalación de Node.js. 
  >pamac install nodejs
  Preparando...
  ...

  >node --version
  v24.8.0


Una vez realizada la instalación de node.js es necesario instalar la CLI de Angular. Para ello utilizaremos el gestor de paquetes de Node.js, npm. 
  >sudo npm install -g @angular/cli
  added 315 packages in 15 s

A continuación realizamos la instalación de TypeScript desde la línea de comandos. 
  >sudo npm install -g typescript
  >tsc -v
  Version 5.9.3

Con todo instalado ya estamos en disposición de crear el primer proyecto y comenzar a trabajar con Angular.
