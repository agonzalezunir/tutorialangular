Componentes (I)

La estructuración de un proyecto de Angular se basa en componentes.
Cada componente tiene una serie de ficheros que sirven para diferentes cosas.
Vamos a seguir la estructuración de esta página de tutorial y vamos a:
  • Crear un componente de cabecera
  • Crear un componente de barra de navegación
  • Crear un componente de visualización (como el de este texto)
  • Ver todo lo que tenemos que tocar para conseguir que funcione...

La creación de componentes se realiza mediante la línea de comandos. Por ejemplo, en nuestro caso, si queremos crear el componente 'introduccion' (que correspondería con el primer capítulo de este tutorial), abriríamos el terminal, iríamos a la ruta src/app de nuestro proyecto y ejecutaríamos: 
  >ng generate component pages/introduccion
  CREATE src/app/pages/introduccion/introduccion.css (0 bytes)
  CREATE src/app/pages/introduccion/introduccion.spec.ts (573 bytes)
  CREATE src/app/pages/introduccion/introduccion.ts (210 bytes)
  CREATE src/app/pages/introduccion/introduccion.html (27 bytes)

Vemos que nos ha creado cuatro ficheros:
  • introduccion.css es el fichero de estilos, al igual que en cualquier aplicación web
  • introducion.html contiene el código html del componente
  • introduccion.ts es el archivo principal del componente, define su clase, sus propiedades, métodos y conexión con HTML/CSS
  • introduccion.spec.ts incluye tests unitarios para comprobar que el componente funciona como debería
Nosotros nos vamos a centrar sobre todo en los ficheros html y css del componente pero sin perder de vista que hay una clase que exporta y que necesitaremos para la navegación.
El componente de cabecera como tal lo incluiremos en el archivo app.html.
Vamos entonces a crear el componente de navegación y ya tendremos todo lo necesario para hacer el primer esbozo del tutorial:
  >ng generate component layout/navbar
  CREATE src/app/layout/navbar/navbar.css (0 bytes)
  CREATE src/app/layout/navbar/navbar.spec.ts (573 bytes)
  CREATE src/app/layout/navbar/navbar.ts (210 bytes)
  CREATE src/app/layout/navbar/navbar.html (27 bytes)
